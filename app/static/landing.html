Click Shield

Wait a second before your AI agent clicks.

A fast Gemini Decision 1 gate checks every click a browser agent makes. Unsure clicks are set off in a Managed Agents sandbox first.

Watch it stop a hijack → Get the Chrome extension
Bring your own Gemini keyCode & evidence on GitHub

Every click gets one of three routes

PASSthe button the task names
DETONATEnot sure: try it in a sandbox
STOPan overt attack

Install the extension

  1. Unzip · chrome://extensions · Developer mode · Load unpacked.
  2. In the repo, run the Shield API: python -m api.server
  3. In the extension options, set your task and Gemini key.

How it works

Agent proposes a click

Gemini 4 Hydrogen computer use picks where to click. Nothing fires yet.

Shield routes it

Decision 1 reads the screenshot, the click and the task, and answers PASS, STOP or DETONATE.
